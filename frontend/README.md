# A2 CRAVINGS 🍝🍗🍟

> **Delicious homemade-style fast food in Rawalpindi**

A premium, fully responsive restaurant website built with **React + Vite**. Features a dark luxury design, smooth animations, WhatsApp ordering integration, and complete SEO optimization.

## ⚡ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
cd <YOUR-REPO-NAME>
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start development server

```bash
npm run dev
```

Runs at **http://localhost:3000**

### 4. Build for production

```bash
npm run build
```

Output is in the `dist/` folder (not committed to Git).

### 5. Preview production build locally

```bash
npm run preview
```
